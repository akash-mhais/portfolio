01_Kinematics & Control

The core challenge of this project was simulating timing and physical interactions between moving bodies on an automated line. The sorting system evaluates items coming down the primary conveyor block and selectively triggers a pneumatic/motorized arm mechanism.

alt_route
Diverter Mechanism

The lateral push arm is actuated in a sweeping motion, interrupting the path of specific packages based on simulated sensor triggers. This forces the sorted package off the primary belt and onto the perpendicular gravity/auxiliary conveyor.

conveyor_belt
Continuous Feed

The primary conveyor models a continuous friction feed system. Target blocks (yellow and red) respond to friction and gravity simulations within SolidWorks Motion to create a realistic flow of materials past the sorting checkpoint.
